## Usage
The model includes:
- `scene.gltf` - Main glTF scene file
- `scene.bin` - Binary geometry data
- `textures/` - PBR texture maps
  - `Hands_Low_defaultMat1_baseColor.jpeg` - Base color/diffuse map
  - `Hands_Low_defaultMat1_metallicRoughness.png` - Metallic/roughness map
  - `Hands_Low_defaultMat1_normal.png` - Normal map
